# F50: 法律事務、處分裁罰與評議爭議智庫 - 測試計畫 (F50_TEST_PLAN.md)

## 1. 測試目標
驗證 F50 模組自包含生命週期、499 筆處分書 XML 解析入庫、FTS5 違規事實全文檢索、評議申訴主檔、以及進階缺失裁罰演進追蹤與 F00 監理雷達罰鍰回寫之正確性。

## 2. 測試案例清單
- **[TCV-F50-001] 隔離環境自包含生命週期與 ETL 匯入驗證**：在臨時隔離 DB 中建表並匯入全量處分書與評議資料（裁罰處分 >= 450 筆，評議爭議 >= 20 筆）。
- **[TCV-F50-002] 裁罰罰鍰金額與關鍵資訊解析驗證**：驗證合庫、台新等重大裁罰案之罰鍰數值解析正確（如 12,000,000 元）。
- **[TCV-F50-003] FTS5 全文倒排檢索驗證**：檢索「信用卡疑義帳款」、「資安」關鍵字，驗證命中具體處分書。
- **[TCV-F50-004] 機構累計裁罰排行檢視驗證**：驗證 `v_f50_institution_sanction_summary` 排序正確性。
- **[TCV-F50-005] 金融消費評議申訴查詢驗證**：查詢爭議案件排行與申訴比率。
- **[TCV-F50-006] 進階缺失 ➔ 裁罰演進追蹤與雷達回寫驗證 (Advanced)**：驗證 F40 缺失與 F50 處分關聯，以及罰鍰回寫 `f00_supervisory_radar`。
