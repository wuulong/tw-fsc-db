# 🏛️ F00: 金管會母大腦全域倒排與元資料治理中心 (f00_master_hub)

本子模組為 `tw-fsc-db` (金融監督管理委員會開放資料智庫) 之全域神經母中樞。

## 📁 職責與架構
* **責任範圍**：
  1. 治理專案全域子模組註冊 (`sys_module_metadata`)，記錄各模組資料表筆數與更新時間。
  2. 建立全域 FTS5 倒排索引 (`fts_fsc_global`)，橫跨銀行、證券、保險、檢查缺失與合規 VASP。
  3. 提供全專案頂層搜尋與健康態勢監控 API。
* **自包含獨立性**：
  * `schema.sql`：定義 `sys_module_metadata` 與 `fts_fsc_global` 虛擬表。
  * `etl.py`：掃描並聚合已入庫之各模組實體，注入全域倒排索引。
  * `commands_f00.py`：提供全域全文檢索與模組註冊查詢函式。
  * `tests/test_f00.py`：獨立單元測試（可對記憶體或隔離臨時 DB 驗證）。
