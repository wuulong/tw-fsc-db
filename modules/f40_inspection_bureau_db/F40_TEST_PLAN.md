# F40: 金融檢查與重大缺失智庫 - 測試計畫 (F40_TEST_PLAN.md)

## 1. 測試目標
驗證 F40 模組自包含生命週期、FTS5 全文檢索虛擬表、檢查執行主表、業務專案高頻統計檢視表，以及進階跨模組集團股權拓樸穿透與監理綜合風險雷達計分之正確性。

## 2. 測試案例清單
- **[TCV-F40-001] 隔離環境自包含生命週期與 ETL 匯入驗證**：在臨時隔離 DB 中建表並匯入全量真實資料（缺失數 >= 90，檢查統計數 >= 40）。
- **[TCV-F40-002] FTS5 全文倒排檢索驗證**：檢索「創投」關鍵字，驗證命中金控對創投子公司管理之具體缺失。
- **[TCV-F40-003] 高頻業務缺失分類檢視驗證**：驗證 `v_f40_deficiency_category_summary` 之百分比合計與排名正確性。
- **[TCV-F40-004] 檢查局實地檢查執行年度統計驗證**：查詢一般檢查與專案檢查家數分佈。
- **[TCV-F40-005] API 函式邊界條件與容錯驗證**：空關鍵字、非法業別過濾之容錯性。
- **[TCV-F40-006] 缺失態樣穿透集團股權拓樸驗證 (Advanced)**：驗證 `query_holding_deficiency_penetration` 能將金控缺失穿透至旗下銀行、產險、證券、創投或 AMC 受控實體與其經營指標。
- **[TCV-F40-007] 重大缺失計分下沉監理雷達驗證 (Advanced)**：驗證 `sync_deficiency_supervisory_radar` 成功寫入 `f00_supervisory_radar` 並產出對應之紅黃綠風險燈號。
