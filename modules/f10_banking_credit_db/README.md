# 🏛️ F10: 金融機構名錄與金控資產品質模組 (f10_banking_credit_db)

本子模組為 `tw-fsc-db` (金融監督管理委員會開放資料智庫) 核心第一基石模組。

## 📁 職責與架構
* **責任範圍**：管理全台金融控股公司結構、子公司網路、本國銀行設立、總分支機構及資產品質（逾放比率、備抵呆帳涵蓋率、存放款規模）。
* **自包含獨立性**：
  * `schema.sql`：定義 `f10_financial_holdings` (金控) 與 `f10_bank_asset_quality` (資產品質)。
  * `etl.py`：清洗入庫腳本，支援 `--db` 參數指定目標資料庫（預設為 `db/fsc.db`）。
  * `commands_f10.py`：提供子模組專屬查詢與統計 API。
  * `tests/test_f10.py`：獨立單元測試（可對記憶體或隔離 DB 驗證）。
